# RegistroIncidencias

## Propósito
Aplicación Android para el registro de incidencias y actividades de mantenimiento en campo, orientada a sistemas fotovoltaicos (PV). Permite generar una bitácora técnica con datos de inspección, mediciones y estado operativo de equipos durante actividades de operación y mantenimiento (O&M).

## Herramientas utilizadas
- Android Studio
- Kotlin
- Jetpack Compose
- Git / GitHub

## Estado actual
- Pantalla inicial funcional: "Bitácora Técnica de Campo — Sistemas FV"
- Estado de inspección con botón de inicio ("Iniciar bitácora de inspección")
- Prototipo inicial — Unidad 1
- Pendiente: implementar captura de datos ambientales, mediciones eléctricas AC/DC, geolocalización y evidencia fotográfica.

## Cómo abrir el proyecto
1. Clonar este repositorio.
2. Abrir Android Studio.
3. Seleccionar **Open** y elegir la carpeta del proyecto clonado.
4. Esperar a que Gradle sincronice las dependencias.
5. Ejecutar la app en un emulador o dispositivo físico.
